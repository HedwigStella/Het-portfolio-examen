# Het-portfolio-examen
Workshopplatform en het portfolio examen 

## Paginanavigatie workshops

### Bestand en toepassing
- Bestand: css/workshop-paginering.css
- Locatie in WordPress: Oxygen → Stylesheets → custom → workshop-paginering
- Gebruikt op: de pagina Workshops
- Gekoppelde eis: eis 1, workshopoverzicht
- Examenbewijs: B1-K1-W3, eigen CSS en versiebeheer

### Doel
- De paginanavigatie sluit aan op de huisstijl van de website.
- De knoppen staan gecentreerd en de huidige pagina is zwart gemarkeerd.
- Er worden vier workshops per pagina getoond.

### Werking
De class workshop-overzicht bepaald de opmaak in het workshopoverzicht.
Flexbox centreert de paginaknoppen en 'gap' bepaalt de tussenruimte.
De class current markeert de huidige pagina.
Hover geeft feedback bij aanwijzen met de muis.
Focus-visible maakt toetsenbordbediening zichtbaar.

### Werkwijze bij wijzigingen
Ik houd dit CSS-bestand en de Oxygen-stylesheet gelijk.
Na een wijziging controleer ik de werking in de browser.
Daarna leg ik de wijziging vast met een duidelijke Git-commit.
